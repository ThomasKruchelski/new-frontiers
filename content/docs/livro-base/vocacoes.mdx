    # Médico

    <li> Medicina </li>
    <li> Primeiros socorros </li>
    <li> Pesquisa ( Química, Biologia) </li>
    <li> Dirigir automovel </li>
    <li> Ofício </li>
    <li> Pistola/Arremesso </li>

    Médico pode escolher 1 perícia dessa lista para ter vantagem em seus testes
    
    Tambem recebe a habilidade da vocação '**Médico de Campo**'

    <div className='box-border mb-12'>
        ### Médico de campo

        Você pode usar kits-médicos durante uma cena de combate. Ao usar uma ação padrão e ser bem sucedido em um teste de medicina ou primeiros socorros para curar outro jogador, você cura equivalente ao valor obtido nos dados sem bônus adicional.
    </div>
